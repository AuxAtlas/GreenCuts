# Green Cuts

# NOTICE OF ARCHIVED BRANCH
This branch '1.20.1-archived' was archived in September 2025
due to a complete rewrite of Greencuts to multi loader.
The **GreenCuts** project is still active and being developed.
Please refer to the [Modrinth page](https://modrinth.com/mod/greencuts) for more information.

## About
Green Cuts is a highly configurable sapling auto-planing mod. It has a chance to plant
saplings when they fall from trees.
